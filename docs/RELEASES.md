# Release policy

1. Source code lives on `main`.
2. Generated `android/`, `ios/`, `dist/` directories are not committed.
3. APK / IPA / simulator ZIP / preview bundle are build artifacts, not source files.
4. Stable distribution files belong in GitHub Releases.
5. Version tags use `v55`, `v56`, ...; build numbers are generated by CI.
6. A release must keep the same Capacitor application id unless an intentional migration is documented.
