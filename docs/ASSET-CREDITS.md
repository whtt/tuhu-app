# 资源与依赖

v45 沿用 v43 全部图片和音频，没有重新绘制或重新合成。逐文件一致性见 `v43-resource-audit.json（本版资源未变）`。

## 项目素材

旅行数据沿用本会话 v40 源码。旧数据快照见 `original-v40-data.json`。图片恢复自用户已有图片文件及旧 v26 包，逐图源文件名、尺寸、SHA-256 见 `image-audit.json`。这些参考图含已有作品角色与相关标识，本包不宣称拥有原作品的角色、标识或商标权利。

App 图标取自本会话用户确认的“兔狐旅行助手界面设计展板”中的兔狐图标区域。

## 英语音频

`www/assets/audio/` 为 v42 根据项目已有英语文本生成的93条合成语音；v45 原样保留，使用 eSpeak 英文语音生成波形，经 FFmpeg 编码/响度处理为 MP3。没有分发语音合成器或 FFmpeg 可执行程序。音色偏机械；不标为真人录音、Piper、云端自然语音或任何人的声音。文本、文件映射、时长、原始波形非静音检查见 `audio-audit.json`。

## npm 依赖

Capacitor core / android / cli 固定为7.4.3；App插件7.1.0；社区 text-to-speech 插件6.1.0；esbuild0.25.5。实际安装由 npm 完成，各第三方包的版权和许可证以安装后的 LICENSE / 包声明为准。未附带 node_modules 或伪造的 package-lock。

## 地图

底图通过 OpenStreetMap 官方嵌入页面联网显示，地图数据署名保留于嵌入视图。外部点位链接打开 Google Maps 或已保存的原链接。离线缓存不抓取第三方地图瓦片。

## v47 新增旅行伙伴图

v47 新增的 `www/assets/generated/*_companion.webp` 来自本次对话中生成的旅行拼图，并按画面面板裁切为 App 场景资产。它们包含原神角色与 Judy / Nick 的旅行场景，用于本项目私人旅行助手的主页背景、时间轴、弹卡和补充拍照参考。原 v45 图片与英语音频继续保留。

## v48 生活动作 Moment 图

v48 新增的 `www/assets/moments/*.webp` 来自本次对话中生成的两张 3×2 旅行生活拼图，并裁切为 12 张独立功能卡素材。它们用于私人旅行助手中的执行、路线、吃喝、票夹、住宿和园区功能，不替代景点拍照参考原图。
