# Public repository privacy rules

This repository is public. The following must never be committed:

- passport/ID images or numbers;
- ticket QR/barcodes and boarding passes;
- hotel/flight/train confirmation numbers that identify a booking;
- personal uploaded receipts, PDFs or screenshots;
- Apple certificates, provisioning profiles, API private keys;
- Android signing keystores or passwords.

The app's credential wallet stores imported files locally on the phone. Test fixtures and screenshots used in the repository must contain synthetic or non-sensitive data only.
