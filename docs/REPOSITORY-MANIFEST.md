# Repository manifest

This repository is intentionally split by responsibility rather than by release archive.

## Application source

- `www/index.html` — shared application shell.
- `www/css/app.css` — shared visual system and v55 travel UI.
- `www/js/app.js` — timeline, scene tools, wallet and presentation logic.
- `www/js/trip-data.js` — six-day itinerary and scene data.
- `www/js/audio-data.js` — offline phrase/audio bindings.
- `www/js/image-registry.js` + `www/assets/image-registry.json` — reviewed image bindings.
- `www/js/assistant.js` — offline travel assistant and fallback knowledge.
- `www/js/motion.js` — timeline gesture / inertial motion.
- `www/js/native-bridge.js` + `src/native-bridge.js` — native capability boundary.

## Native integration

- `native/android/MainActivity.java` — Capacitor plugin registration.
- `native/android/TuhuFilesPlugin.java` — private credential file operations.
- `native/android/TuhuLlmPlugin.java` — optional Android GGUF inference.
- iOS platform files are generated by Capacitor; iOS-specific binary assets are kept under the binary-media policy in `docs/MEDIA-ASSETS.md`.

## Build and validation

- `scripts/build.mjs` — shared bundle step.
- `scripts/prepare-android.mjs` — generate/sync Android and apply TUHU native integration.
- `scripts/prepare-ios.mjs` — generate/sync iOS and apply stable bundle/version settings.
- `scripts/check-source.mjs` — source-only repository integrity check.
- `scripts/check-full.mjs` / `scripts/check.mjs` — full runtime-media integrity checks.
- `scripts/export-preview.mjs`, `scripts/serve.mjs`, `scripts/worker.mjs` — preview tooling.
- `scripts/build-image-registry.mjs`, `scripts/register-image.mjs` — image registry maintenance.
- `scripts/smoke-v55.py` — browser-level v55 smoke checks.

## CI / release

- `.github/workflows/ci.yml` — source check on main / pull requests.
- `.github/workflows/android.yml` — Android APK build.
- `.github/workflows/ios.yml` — iOS Simulator or signed TestFlight build.
- `.github/workflows/release.yml` — stable GitHub Release metadata.
- `ci/ExportOptions.plist` — iOS archive export template.

## Documentation

- `docs/ARCHITECTURE.md` — shared / Android / iOS boundaries.
- `docs/BUILDING.md` — local and cloud build commands.
- `docs/MEDIA-ASSETS.md` — runtime binary asset policy.
- `docs/PRIVACY.md` — public-repository privacy boundary.
- `docs/RELEASES.md` — release/tag policy.
- `docs/CHANGELOG-v55.md` — current version changes.
- `docs/ASSET-CREDITS.md` — source/credit notes.

Generated `android/`, `ios/`, `dist/`, install packages, user-imported credentials and signing keys are deliberately not committed as ordinary source files.
