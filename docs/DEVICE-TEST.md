# v56 真机验收清单

目标：Android APK 与 iPhone/TestFlight 各执行一次；关键项目再在飞行模式下执行一次。

## 1. 设置 → 真机自检

先在线运行一次，再开启飞行模式运行一次。

必须通过：
- 设置 / 备忘可写入与读取。
- 票夹 IndexedDB 可写入、读取、删除。
- 离线行程脚本可读取。
- 离线英语 MP3 可读取。

允许显示“信息/需真机确认”：
- persistent storage API：不同 WebView 支持不同。
- iPhone 凭证桥接：当前优先使用系统 Share Sheet，需要实际点一次 PDF 验证。

## 2. 首页

- 刘海 / Dynamic Island / 状态栏不遮挡日期。
- Home Indicator 不压住底部导航。
- 上下滑动阻尼连续，无明显卡顿。
- 左右切换日期不会误触打开卡片。
- 当前卡从当天第一项滑到最后一项最多约两次常规手势能覆盖主要内容。
- 纯文字执行卡与图片卡混排时无明显空洞或跳动。

## 3. 场景卡

抽测：
- 鱼尾狮：拍照 / 拍摄 / 地图 / 执行。
- NTU：拍照 / 拍摄 / 地图 / 导览。
- USS 上午：园区 / 执行 / 地图 / 英语。
- Changi T1：功能摘要、执行、英语、地图。
- D3108：显示火车语义与潮汕 → 上海南，不出现飞机图标。

## 4. 英语

- 场景入口默认只出现 3–5 句“现在最可能用到”。
- 点击“全部语句”可进入完整分类。
- 离线 MP3 可直接播放。
- 锁屏/切后台时声音停止。
- 恢复 App 后可重新播放。
- 0.8× / 1× 切换正常。

## 5. 票夹

准备一张测试截图和一份测试 PDF：

1. 添加到某个订单。
2. 修改持有人标签。
3. 全屏出示。
4. 切换多个凭证。
5. 完全关闭 App（从多任务界面划掉）。
6. 重新打开，确认文件和关联关系仍存在。
7. Android：测试“打开”和“分享”。
8. iPhone：测试“打开 / 分享 PDF”，应进入系统 Share Sheet，可交给 Files / Preview / AirDrop 等。
9. 删除测试文件后确认票夹恢复干净。

## 6. 离线

开启飞行模式后：
- 六天行程可打开。
- 场景详情可打开。
- 已打包的图片可显示。
- 英语 MP3 可播放。
- 已保存票证可打开。
- 备忘可编辑。
- 地图外链、官网等需要网络的功能允许不可用，但不得导致 App 卡死。

## 7. 前后台与重启

- 打开票证 → 切后台 → 回前台，界面仍正常。
- 英语播放中切后台，音频应停止。
- 全屏出示凭证时保持屏幕常亮；退出出示模式后释放常亮。
- 杀进程并重开后，日期选择、备忘、勾选、票夹文件仍存在。

## 8. 发布前最终状态

代码冻结后只允许更新：
- 酒店是否已订。
- ACM / USS 是否已购票。
- D3108 是否已购票。
- 动态登机口 / 检票口等现场信息。

不再在 v56 修改首页结构、卡片手势、票夹架构和英语焦点模式。
